

**Expressions**  
We will start with detecting changes in expressions.  
Identifying the expressions will be done later, as more data is gathered.

FACS is a possibility, however it has been discredited.  
We need to define "similarities" between expression transitions too.

**Data**  
Data collection must have genuine expressions and transitions. Annotations to be done manually, cross-referencing with known video keypoints.

**Session Uniqueness**  
Session uniqueness will be detected using face recognition. N:N face matching to verify uniqueness

**Attention**  
Attention to be measured as a ratio of Eyes-On-Screen-Duration to Eyes-Off-Screen-Duration
